⚙️ Sistem Persamaan Linear (SPL) & Eliminasi Gaussian#

Notebook ini membahas bagaimana memodelkan Sistem Persamaan Linear (SPL) ke dalam bentuk persamaan matriks, serta menyelesaikannya menggunakan Eliminasi Gaussian langkah demi langkah dengan Python.

📖 Pengantar Sistem Persamaan Linear (SPL) Sederhana#

Sebelum masuk ke pemrograman Python, mari pahami konsep dasar SPL dengan cara yang lebih mudah.

Secara visual:

  • Pada ruang 2D, solusi SPL adalah titik potong antar garis.

  • Pada ruang 3D, solusi SPL adalah titik potong antar bidang.

A. Membedakan Persamaan Linear dan Non-linear#

Persamaan disebut linear jika semua variabelnya berpangkat satu dan tidak saling dikalikan atau berada di dalam fungsi lain (seperti trigonometri).

  • Linear:

    • \(2x + 3y = 6\)

    • \(\sqrt{3}x - e^2y = 5\) (angka \(\sqrt{3}\) dan \(e^2\) hanyalah konstanta biasa, bukan variabel).

  • Non-linear:

    • \(x^2 + y^2 = 1\) (variabel memiliki pangkat selain 1).

    • \(xy = 4\) (variabel saling dikalikan).

    • \(\sin(x) + y = 2\) (variabel berada di dalam fungsi trigonometri).

B. Homogen vs. Tak-homogen#

Kita membedakan keduanya dari nilai di ruas kanan persamaan setelah memindahkan semua variabel ke ruas kiri:

  • Homogen: Ruas kanannya sama dengan nol.

    • Contoh: \(2x + y = 0\)

    • Sistem homogen selalu memiliki minimal satu solusi, yaitu solusi trivial (semua variabel bernilai 0).

  • Tak-homogen: Ruas kanannya bukan nol.

    • Contoh: \(2x + y = 5\)

C. Membaca Indeks Ganda (\(a_{ij}\))#

Indeks ganda digunakan untuk melacak koefisien dalam sistem persamaan yang besar:

  • Indeks pertama (\(i\)): Posisi baris (persamaan keberapa).

  • Indeks kedua (\(j\)): Posisi kolom (variabel keberapa).

Misalnya koefisien \(a_{23}\): ini adalah koefisien untuk variabel ke-3 yang berada di persamaan ke-2.

D. Matriks Augmented dan Operasi Baris Elementer (OBE)#

Menulis variabel (\(x, y, z\)) berulang kali sangat melelahkan. Matriks augmented menyederhanakan penulisan dengan hanya mencatat koefisien dan konstanta ke dalam bentuk matriks.

Untuk menyelesaikannya, kita menggunakan tiga operasi dasar (OBE) yang tidak mengubah solusi akhir:

  1. Menukar posisi dua baris jika diperlukan.

  2. Mengalikan sebuah baris dengan angka selain nol.

  3. Menambahkan atau mengurangi kelipatan suatu baris ke baris lainnya untuk membuat angka di bawah pivot menjadi nol.

Tujuannya adalah mengubah matriks menjadi berbentuk segitiga atas (eselon baris), sehingga kita bisa melakukan substitusi balik dari bawah ke atas.

1. Representasi SPL ke Matriks#

SPL dengan \(m\) persamaan dan \(n\) variabel dapat ditulis dalam bentuk: $\(Ax = b\)$

Misal kita memiliki SPL: $\( \begin{aligned} 2x + y + z &= 8 \\ 3x - y - z &= 2 \\ x + 2y - z &= 2 \end{aligned} \)$

Mari representasikan SPL ini ke dalam Matriks Koefisien \(A\), Vektor Konstanta \(b\), dan Matriks Diperbesar (Augmented Matrix) \([A | b]\).

import numpy as np

A = np.array([[2.0, 1.0, 1.0],
              [3.0, -1.0, -1.0],
              [1.0, 2.0, -1.0]])

b = np.array([8.0, 2.0, 2.0])

# Augmented Matrix
augmented = np.column_stack((A, b))
print("Matriks Koefisien A:\n", A)
print("\nVektor Hasil b:\n", b)
print("\nMatriks Diperbesar [A | b]:\n", augmented)

Matriks Koefisien A:
 [[ 2.  1.  1.]
 [ 3. -1. -1.]
 [ 1.  2. -1.]]

Vektor Hasil b:
 [8. 2. 2.]

Matriks Diperbesar [A | b]:
 [[ 2.  1.  1.  8.]
 [ 3. -1. -1.  2.]
 [ 1.  2. -1.  2.]]

2. Eliminasi Gaussian (OBE)#

Eliminasi Gaussian adalah algoritma untuk mengubah matriks diperbesar menjadi bentuk Eselon Baris. Setelah itu, nilai variabel ditentukan dengan Substitusi Balik.

Berikut adalah fungsi Python untuk melakukan Eliminasi Gaussian:

def gaussian_elimination(A, b):
    M = np.column_stack((A, b)).astype(float)
    n = len(b)
    
    # 1. Eliminasi Maju
    for i in range(n):
        # Pencarian Pivot Maksimum (Partial Pivoting)
        max_row = np.argmax(np.abs(M[i:, i])) + i
        if M[max_row, i] == 0:
            raise ValueError("SPL tidak memiliki solusi unik.")
        M[[i, max_row]] = M[[max_row, i]]
        
        # Operasi Baris untuk membuat elemen di bawah pivot menjadi nol
        for j in range(i + 1, n):
            factor = M[j, i] / M[i, i]
            M[j, i:] -= factor * M[i, i:]
            
    # 2. Substitusi Balik
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):
        x[i] = (M[i, -1] - np.dot(M[i, i+1:n], x[i+1:n])) / M[i, i]
        
    return x

solusi = gaussian_elimination(A, b)
print("Solusi SPL hasil Eliminasi Gaussian:", solusi)

Solusi SPL hasil Eliminasi Gaussian: [2.         1.33333333 2.66666667]

3. Penyelesaian Instan dengan NumPy#

Untuk kebutuhan praktis, kita dapat memanggil np.linalg.solve(A, b) secara langsung.

solusi_numpy = np.linalg.solve(A, b)
print("Solusi np.linalg.solve:", solusi_numpy)

Solusi np.linalg.solve: [2.         1.33333333 2.66666667]
